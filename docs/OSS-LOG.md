# Open-source contribution log

Building this project teaches Vue. It does not teach how to join a team already
mid-flight — reading before writing, matching someone else's conventions over your
own preferences, and getting a change through a reviewer who does not know you.
That is a separate skill, and shipping small PRs to an active Vue repository is
the only item on the plan that rehearses it directly.

Target: **three merged PRs** during Phases 2-5.

## Candidate repositories

Pick ones with active issues and a visible review culture:

- [VueUse](https://github.com/vueuse/vueuse) — small, well-tested composables; good first-PR surface
- [PrimeVue](https://github.com/primefaces/primevue) — large component library, many small bugs
- [FormKit](https://github.com/formkit/formkit) — forms, which is directly relevant here
- A Nuxt module — narrower scope, faster review cycles

## What to practise on each PR

- Trace the feature end to end **before** editing anything
- Match the surrounding conventions, even where you would have chosen differently
- One concern per PR, with a description that says why
- Write the test that proves the fix
- Use `git blame`, `git bisect` and interactive rebase rather than guessing
- Debug with Vue DevTools and breakpoints rather than `console.log`
